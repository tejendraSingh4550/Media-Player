# Pulse Media Player

A lightweight, browser-based local media player. It plays audio and video files directly from your device; files are not uploaded.

## Run it

Open `index.html` in a modern browser, then select files or drag them onto the page. No install or server is required.

## Features

- Audio and video playback for browser-supported formats
- Queue with play, remove, clear, previous, next, shuffle, and repeat
- Drag and drop files, seek, volume, and light theme
- Keyboard shortcuts: Space to play or pause, Left/Right to seek, Up/Down to adjust volume
